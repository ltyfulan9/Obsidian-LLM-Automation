# 验证记录

## v0.4.0

- 本机完整 59 项测试通过；跨平台结果以对应提交的 Actions 为准。
- 新增每日回填合并/更正、未来日期拒绝、机密过滤、旧数据库升级、承诺状态流转与实际结果必填测试。
- 用虚构事件验证历史周不计入后来完成的结果、取消后不计逾期、重复阻碍按不同日期计数、无记录天数标为未知。
- 验证个人记录参与搜索、同步不抹除回填、AI 资料不自动创建承诺、渲染失败后已保存事实可无模型重建。
- 本地合成 Git remote 试验包含个人复盘与承诺页面；公开演示使用固定虚构日历与资料，不采集真实个人历史。
- 实际 Python CLI 子进程完成初始化、添加承诺、两次改期、三天回填、复盘、搜索和两次同步；三条模式均触发，个人记录保留。
- 演示共 22 个生成文件，94 个相对链接及 Canvas 文件引用有效；连续生成两次内容哈希一致。
- 本版本复盘不调用模型；未启用或替换用户机器上的生产定时任务。

## v0.3.0

- 本机 47 项测试通过，新增中断生成恢复、人工编辑保护、并发锁、模型缓存/重试和超时清理测试。
- Magpie 小包测试验证确定性 gzip、4 KiB 小预算淘汰统计、默认 64 KiB 上限、私有目标检查及未登记集成包时明确失败。
- 实际 Windows 临时任务使用虚构对话调用 Claude，退出码为 0，生成 1 份小结；第二次运行 `updated=0`、`unchanged=1`。试验任务已移除。
- Magpie 的实际私人压缩包未作为公开测试数据；公开集成包不含用户对话。
- 每日 21:00 的配置和接入步骤已提供；“生成配置”不等于任何用户机器已启用任务。
